# ArraysPractice

Java Arrays: Practice Exercises

## Tasks Overview

### Task 1. Count Positive, Negative, and Zero Values
- Counts positive, negative, and zero values in an integer array of 10 numbers without using advanced library functions.

### Task 2. Largest and Smallest Elements
- Finds the largest and smallest elements and their indices in an array of 8 integers without built-in `Math.max`, `Math.min`, or sorting.

### Task 3. Numbers Greater Than the Average
- Calculates the sum and average of an array with 6 integers and counts elements strictly greater than the average.

### Task 4. Print an Array in Reverse Order
- Prints an array of 7 integers in original order and in reverse order without modifying the original array.

### Task 5. Student Test Scores
- Prompts user to input 5 test scores (0-100), validates input, counts passed (>= 60) and failed (< 60) scores, and computes the average score.

## How to Compile and Run

To compile all files:
```bash
javac *.java
```

To run individual tasks:
```bash
java Task1
java Task2
java Task3
java Task4
java Task5
```

Or run all tasks together:
```bash
java HW10
```
